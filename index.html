🛰️ Remote Claude Setup

Everything to enable so you can drive Claude Code from your iPhone

🎉 All set! Open claude.ai/code on your iPhone and find your session.
Progress0 / 0

1 · Requirements

Claude Code v2.1.51 or newer
Run claude --version in Terminal. Update with claude update if older.
Signed in with claude.ai account
Run /login inside Claude Code. Must be a claude.ai account, not an API key.
Pro, Max, Team, or Enterprise plan
Team/Enterprise: an admin must enable Remote Control in admin settings.

2 · Enable on your Mac

Start a Remote Control session
Type /remote-control My Project in a running session, or launch with claude --remote-control "My Project".
Enable for all sessions (optional)
Run /config → toggle "Enable Remote Control for all sessions".
Turn on push notifications (optional)
Run /config → enable "Push when Claude decides". Needs v2.1.110+.

3 · Connect your iPhone

Install the Claude app on iPhone
Sign in with the same claude.ai account you used on your Mac.
Scan the QR code or open claude.ai/code
Your session shows a QR code in the terminal. Or tap Code in the Claude app and find the session by name (green dot = online).
Send a test message from your phone
It appears in your Mac terminal instantly — terminal and phone stay in sync.

⚠️ Remember

Keep your Mac awake & Claude running
Closing the terminal ends the session. Network outages over ~10 min time it out.
Docs: code.claude.com/docs/en/remote-control
